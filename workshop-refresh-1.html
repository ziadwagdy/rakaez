بعد ورشة السبت — تطبيق منزلي حتى الخميس

أنجزنا HTML وCSS خلال ورشة السبت ذات الأربع ساعات. المطلوب في المنزل تثبيت ما تعلمناه، لا إعادة الورشة كاملة. المدة الإجمالية ٣٠–٤٥ دقيقة، ويمكن توزيعها هكذا:

اليومالمراجعة المطلوبة
الأحد ١٥ نوفمبرافتح مشروع السبت وتأكد من ظهور البطاقات الأربع وعمل CSS.
الاثنين ١٦ نوفمبرأعد كتابة بطاقة المسافة دون النظر للمثال، ثم قارنها وأصلحها.
الثلاثاء ١٧ نوفمبرغيّر لون العنوان وpadding، وتوقّع ثم راقب النتيجة.
الأربعاء ١٨ نوفمبراكتب ملاحظاتك وإجابتك عن الفرق بين id وclass ودور flex.
الخميس ١٩ نوفمبرراجع المشروع وارفع ZIP وصورة وملاحظاتك داخل مجلدك في Drive.

العمل والتسليم فرديان. اترك script.js فارغًا؛ نبدأ JavaScript في الورشة الثانية.

قبل الحضور — تجهيز بسيط (١٥ دقيقة)

تأكد من وجود VS Code وLive Server على جهازك، وأنشئ مجلد rasd-dashboard إن لم يكن موجودًا. افتحه من File → Open Folder. أحضر جهازك والشاحن. إذا كنت تملك مشروع رصد قديمًا، احتفظ بنسخة منه قبل أي تعديل.

بين اللقاءين — تطبيق منزلي (٣٠–٤٥ دقيقة)

طبّق على rasd-dashboard نفسه قبل حضور اللقاء الثاني. لا تبدأ JavaScript بعد؛ الهدف أن تصل بصفحة HTML وCSS تعمل.

ارفع ZIP محدّثًا باسمك و«الورشة ١» داخل مجلدك الخاص في Drive. ارفع صورة للنتيجة وملاحظاتك بجانبه. الموعد: الخميس ١٩ نوفمبر ٢٠٢٦. أحضر المجلد نفسه على جهازك للقاء الثاني.

📁 التسليم والمتابعة

ارفع مجلد rasd-dashboard كاملًا بصيغة ZIP داخل مجلدك الخاص في Google Drive. ابحث عن مجلد اسمه اسمك وارفع الملف بداخله. كل طالب ينفذ مشروعه ويسلّمه بنفسه؛ لا يوجد تقسيم إلى مجموعات أو تسليم جماعي.
