ما دور هذا الجزء في المشروع؟

CSS يحدد ألوان البطاقات وأحجامها وترتيبها، مثل الطلاء والأثاث في الغرفة. نغيّر مظهر لوحة العرض نفسها، ولا نوصل أي جهاز بعد.

▶ النتيجة التي ستحصل عليها

أربع بطاقات بقيم مؤقتة؛ لا توجد قراءات حقيقية بعد.

نواصل اللقاء الأول — الدقائق ٩٥–٢٤٠

هذا الجزء يكمل HTML من الجزء الأول. احفظ نسخة منه قبل التعديل. ١٥ دقيقة للربط والألوان، ٣٥ دقيقة للتنسيق، استراحة ١٠ دقائق، ثم تجارب واكتشاف أخطاء ومراجعة وتسليم.

1 — أكمل المشروع السابق

افتح rasd-dashboard نفسه. أضف السطر التالي داخل head في index.html.

داخل head
<link rel="stylesheet" href="style.css">

2 — صمّم البطاقات

انسخ إلى style.css. أكمل السطرين المعلّمين: لون العنوان باستخدام color، وترتيب الصف باستخدام display: flex. الكود يعمل قبل الإكمال، لكن يظهر التصميم المطلوب بعد إضافتهما. احفظ وشاهد الفرق.

style.css
body {
  background-color: #0d1117;
  color: #e6edf3;
  font-size: 18px;
  text-align: center;
  margin: 0;
  padding: 24px;
}
h1 {
  /* أكمل ١ هنا: اكتب color: ثم لون العنوان ثم ; */
  font-size: 36px;
  font-weight: 900;
}
.cards {
  /* أكمل ٢ هنا: اكتب display: ثم قيمة الصف ثم ; */
  justify-content: space-evenly;
}
.card {
  background-color: #161b22;
  padding: 20px;
  margin: 8px;
  border-radius: 12px;
}
h2 {
  font-size: 18px;
  font-weight: 700;
}
.value {
  color: #f0b429;
  font-size: 12px;
  font-weight: 700;
}

استراحة — الدقائق ١٤٥–١٥٥

احفظ التنسيق ثم ابتعد عن الشاشة عشر دقائق.

غيّر وراقب — الدقائق ١٥٥–١٨٥

توقّع أولًا، ثم غيّر واحفظ وراقب. هذه الملاحظات لا تُحفظ عند إعادة تحميل الصفحة؛ انسخها إلى ملف ملاحظات أو اكتبها على ورقة.

مختبر الأخطاء — الدقائق ١٨٥–٢١٠

١) احفظ نسخة سليمة من الملفات. غيّر اسم ملف الربط من style.css إلى styles.css في HTML. توقّع النتيجة، افتح الصفحة، ثم أصلح الاسم (١٠ دقائق).

٢) غيّر المحدد .cards في CSS إلى .cardz. ما الجزء الذي توقف عن العمل؟ قارنه باسم class في HTML وأصلحه (١٠ دقائق).

آخر ٥ دقائق: اكتب لكل خطأ «العَرَض ← السبب ← الإصلاح». لا تترك الأخطاء في النسخة النهائية.

مراجعة فردية — الدقائق ٢١٠–٢٣٠

افتح مشروعك وراجع كل نقطة بنفسك: أربع بطاقات، أربعة حساسات صحيحة، ملف CSS مرتبط، صف باستخدام flex، ومسافات مقروءة. اكتب شرحًا لبطاقة واحدة وسطر CSS. قارن بالنتيجة المطلوبة، وأصلح نسختك بنفسك، وسجّل أي سؤال تحتاج أن تسأله للمدرب.

بين اللقاءين — تطبيق منزلي (٣٠–٤٥ دقيقة)

طبّق على rasd-dashboard نفسه قبل حضور اللقاء الثاني. لا تبدأ JavaScript بعد؛ الهدف أن تصل بصفحة HTML وCSS تعمل.

ارفع ZIP محدّثًا باسمك و«الورشة ١» داخل مجلدك الخاص في Drive. ارفع صورة للنتيجة وملاحظاتك بجانبه. الموعد: الخميس ١٩ نوفمبر ٢٠٢٦. أحضر المجلد نفسه على جهازك للقاء الثاني.
