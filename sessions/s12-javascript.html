المفهوم الأول

المتغيرات — Variables

صناديق لتخزين البيانات. نستخدم let أو const.

// let — يمكن تغيير قيمته لاحقاً let temperature = 28; temperature = 30; // تغيير مسموح // const — لا يتغير أبداً const projectName = "رصد"; // console.log — لطباعة الناتج في المتصفح console.log(temperature); // 30 console.log(projectName); // رصد
let
للمتغيرات التي قد تتغير — مثل قراءة الحساس
const
للثوابت — مثل اسم المشروع أو رابط الـ API
أداة المطور

الـ Console — مختبرنا

المتصفح يحتوي على Console تكتب فيه JS مباشرةً. افتحه بـ F12 ثم اختر Console.

> let x = 5; > let y = 10; > console.log(x + y); 15 > let name = "رصد"; > console.log("مرحباً من مشروع " + name); مرحباً من مشروع رصد > console.log(28 * 2); 56
🎯 تجربة الآن: افتح المتصفح ← F12 ← Console ← اكتب console.log("مرحبا") واضغط Enter.
المفهوم الثاني

الدوال — Functions

مجموعة أوامر نسمّيها ونستدعيها متى أردنا. بدلاً من تكرار الكود، نكتبه مرة واحدة ونستخدمه كثيراً.

// تعريف الدالة function sayHello() { console.log("مرحباً من رصد!"); } // استدعاء الدالة sayHello(); // مرحباً من رصد! sayHello(); // مرحباً من رصد! // دالة تأخذ قيمة وتعمل بها function showTemp(temp) { console.log("درجة الحرارة: " + temp + " °C"); } showTemp(28); // درجة الحرارة: 28 °C
التحكم في الصفحة

الـ DOM — غيّر أي نص في صفحتك

DOM = الطريق بين JavaScript وعناصر الـ HTML. نصل لأي عنصر عن طريق id.

/* في HTML */ // <h1 id="temp-display">-- °C</h1> /* في JS — نمسك العنصر ونغيّر نصه */ const el = document.getElementById("temp-display"); el.innerHTML = "28 °C"; /* الآن الصفحة تُظهر: 28 °C */
getElementById()
تمسك العنصر الذي له هذا الـ id في HTML
.innerHTML
تغيّر ما يظهر داخل العنصر من نص أو HTML
كيف يعمل رصد

الـ API — باب بيانات رصد

مشروع رصد عنده خادم Python/Flask يعطيك البيانات الحية عند الطلب. كل ما عليك هو أن تطلب.

الرابط: http://localhost:8080/api/latest
RESPONSE — ما يُعيده الخادم (JSON):
{ "temperature": 28.4, "humidity": 63, "water_level": 41230, "soil_moisture": 37800 }
JSON = بيانات منظمة يفهمها JavaScript مباشرةً. كل رقم في مكانه باسم واضح.
طلب البيانات

fetch() — اطلب وخذ

fetch() ترسل طلباً للخادم وتنتظر الرد. نستخدم .then() لما يصل الرد.

fetch("http://localhost:8080/api/latest") .then(function(response) { return response.json(); // حوّل الرد إلى بيانات }) .then(function(data) { // data الآن تحتوي أرقام الحساسات console.log(data.temperature); // 28.4 console.log(data.humidity); // 63 });
  • 1
    fetch() ترسل الطلب إلى رابط الـ API
  • 2
    الخادم يرد بـ JSON
  • 3
    response.json() تحوّل الرد لبيانات JS
  • 4
    data.temperature وdata.humidity تعطيك الأرقام
الكود الكامل

اربط رصد بالبيانات الحية

أضف هذا الكود داخل <script> في نهاية صفحتك.

function updateData() { fetch("http://localhost:8080/api/latest") .then(function(r) { return r.json(); }) .then(function(data) { document.getElementById("temp").innerHTML = data.temperature + " °C"; document.getElementById("humid").innerHTML = data.humidity + " %"; document.getElementById("rain").innerHTML = data.water_level; document.getElementById("soil").innerHTML = data.soil_moisture; }); } updateData(); // شغّل فوراً setInterval(updateData, 3000); // كل 3 ثوانٍ
setInterval(updateData, 3000) تعني: كرّر هذه الدالة كل 3000 مللي ثانية (3 ثوانٍ). هذا ما يجعل الأرقام تتحدث تلقائياً.
