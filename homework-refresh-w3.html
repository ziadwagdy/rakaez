١ — استرجع مشروعك (من ٥:٠٠ إلى ٥:٢٠)

افتح rasd-dashboard من اللقاء الأول. دون النظر إلى المثال، سمِّ دور HTML وCSS وJS ودور كل جزء في مخطط المشروع. افتح index.html بـ Live Server، وتحقق من البطاقات الأربع وملف CSS وأسماء id. أصلح أي ملف ناقص قبل المتابعة.

إذا انتهيت مبكرًا: اكتب بكلماتك كيف يصل CSS إلى جميع البطاقات عبر class وكيف سنصل إلى قيمة واحدة عبر id.

٣ — دالة القراءة التجريبية (من ٥:٤٥ إلى ٦:٢٠)

أضف هذا الكود بعد الثوابت. Math.random هو حساس محاكى حتى يصل Pico الحقيقي. يولّد عددًا من ٠ إلى أقل من ١؛ الضرب والجمع يغيّران مداه. الأرقام العشرية الطويلة طبيعية.

١٠ دقائق: اشرح كيف تتكون الحرارة من ٢٠ إلى أقل من ٤٠. ١٥ دقيقة: أكمل سطر الرطوبة المعلّم. ١٠ دقائق: احفظ، أعد تحميل الصفحة ثلاث مرات، وسجّل لماذا تغيرت القراءات ولماذا لا تتغير وحدها بعد.

script.js — بعد الثوابت
function updateReadings() {
  let temperature = Math.random() * 20 + 20;
  let humidityValue = Math.random() * 100;
  let waterLevel = Math.random() * 100;
  let distanceValue = Math.random() * 200;

  temp.textContent = temperature + " °C";
  // أكمل: حدّث humidity باستخدام humidityValue ووحدة %.
  water.textContent = waterLevel + " %";
  distance.textContent = distanceValue + " cm";
  console.log(temperature);
}

updateReadings();

احفظ مشروعك وخذ عشر دقائق بعيدًا عن الشاشة.

٤ — اجعل القراءات تتكرر (من ٦:٣٠ إلى ٦:٥٠)

أضف السطر مرة واحدة في نهاية script.js، بعد updateReadings(). راقب ثلاث دورات وقِس الزمن. جرّب 1000 ثم أعد 3000. اشرح الفرق بين استدعاء الدالة مرة وتكرارها بمؤقت.

script.js — آخر سطر
setInterval(updateReadings, 3000);

لا تنسخ الدالة أو المؤقت مرتين. بعد أي تعديل احفظ وأعد تحميل الصفحة.

٥ — ابنِ التنبيه (من ٦:٥٠ إلى ٧:٣٠)

أضف الكود التالي داخل updateReadings بعد تحديث النصوص وقبل console.log، وليس خارج الدالة. ١٥ دقيقة لشرط الحرارة، ١٠ لشرط الماء وإكمال سطر إعادة اللون، و١٥ لشرح alert وسطر الحالة.

يبدأ alert بالقيمة false في كل قراءة. أي شرط خطر يحوّله إلى true. إذا كانت الحرارة آمنة، لا نلغي تنبيه الماء. حد الماء ٧٠٪ للتدريب فقط.

٦ — غيّر وراقب: اختبر الحدود (من ٧:٤٠ إلى ٨:١٠)

٧ — مختبر الأخطاء الفردي (من ٨:١٠ إلى ٨:٣٠)

٨ — اشرح مشروعك (من ٨:٣٠ إلى ٨:٤٥)

راجع نسختك وأجب بكلماتك: أي سطر يختار العنصر؟ أي سطر يغيّر النص؟ لماذا 3000؟ متى يعود اللون الأصلي؟ أين ستصل بيانات Pico لاحقًا؟ اكتب إجاباتك في ملاحظاتك، ثم جرّب أمام نفسك ما شرحته. دوّن سؤالًا للمدرب إذا بقي شيء غير واضح.
